# CYBORG — Future Interface Landing Page

A responsive, cyborg-themed landing page built with HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. Scroll through the page and test the navigation menu at mobile width.

## Files
- `index.html` — page content and sections
- `style.css` — layout, colors, responsive styling, and CSS illustration
- `script.js` — mobile navigation toggle

## Before submitting
- Create a GitHub repository and upload these three files plus this README.
- Open the deployed/local page and record a short screen demo (about 30–60 seconds).
- Upload the recording to Google Drive and set General access to “Anyone with the link — Viewer”.
- Submit the GitHub repository URL and the Google Drive recording URL as instructed by the task.
